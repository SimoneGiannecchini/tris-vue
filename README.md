# 🕹️ Tic Tac Toe (Tris) in Vue 3

Gioco del Tris (Tic Tac Toe) sviluppato in **Vue 3** con **Composition API**, componenti modulari e punteggio salvato in `localStorage`.  
Un progetto didattico che dimostra l'uso corretto di props, eventi e struttura a componenti.

👉 **Demo online**:  
https://simonegiannecchini.github.io/tris-vue/

---

## 🚀 Funzionalità

- ✅ Griglia 3x3 dinamica
- ✅ Alternanza X / O a ogni turno
- ✅ Rilevamento automatico del vincitore
- ✅ Punteggio persistente salvato nel browser
- ✅ Pulsante per nuova partita
- ✅ Pulsante per azzerare tutto
- ✅ Stili CSS separati
- ✅ Deployment con GitHub Pages

---

## 🛠️ Tecnologie usate

- [Vue 3](https://vuejs.org/) (Composition API + `<script setup>`)
- [Vite](https://vitejs.dev/) per lo sviluppo veloce
- `gh-pages` per la pubblicazione


---

## 📦 Installazione locale

```bash
git clone https://github.com/SimoneGiannecchini/tris-vue.git
cd tris-vue
npm install
npm run dev
```
