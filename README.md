# 🧠 Tris Vue – Gioco del Tris (Tic-Tac-Toe)

Benvenuto in **Tris Vue**, un semplice ma elegante gioco del tris sviluppato con **Vue 3** e **Vite**.  
Un mini-progetto pensato per due giocatori che si alternano con X e O su una griglia 3x3.

---

## 🎮 Funzionalità

- Griglia dinamica 3x3
- Alternanza automatica tra giocatore X e O
- Primo clic = X, secondo = O, e così via
- Pulsante **"Reset partita"**: svuota solo la griglia mantenendo il punteggio o la sessione attiva
- Pulsante **"Reset tutto"**: resetta completamente anche eventuali contatori/statistiche (se presenti)
- Interfaccia minimale e responsiva

---

## 🛠️ Tecnologie utilizzate

- [Vue 3](https://vuejs.org/)
- [Vite](https://vitejs.dev/)
- HTML + CSS Vanilla
